## How to Download the Data
1. Go to the [competition data page](https://www.kaggle.com/competitions/cmi-detect-behavior-with-sensor-data/data) and accept the competition rules.
2. Download the dataset files (`train.csv`, `train_demographics.csv`, `test.csv`, `test_demographics.csv`).
3. Place the downloaded files into the `data/` directory in the project root.

## How to Run the Notebooks
1. Install the required packages:
   ```bash
   pip install -r requirements.txt
   ```
2. Open and run `assignment1_eda_baseline.ipynb`.
